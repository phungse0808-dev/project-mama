### ข.4 ตารางที่ 1.1 แถวรวมขัดกันเอง

แถวสุดท้ายเขียน "รวม 16 **0**" แต่แถวที่ 16 ช่องราคาเขียนว่า "มีอยู่เเล้ว"
ซึ่งไม่ใช่ตัวเลข การรวมเป็น 0 จึงไม่สอดคล้องกับแถวในตาราง

แก้เป็น

> รวม 16 รายการ · ค่าใช้จ่ายรวม 0 บาท

หรือเปลี่ยนช่องราคาของแถวที่ 16 เป็น "0 (ใช้เครื่องที่มีอยู่เดิม)" แล้วคงแถวรวมไว้เหมือนเดิม

### ข.7 ข้อสังเกตที่ควรแก้ แต่ไม่ใช่ข้อผิดพลาด

**1.1 ความเป็นมาไม่มีตัวเลขและไม่มีการอ้างอิง** ทั้งหัวข้อเป็นข้อความบรรยายว่าฝุ่น
"ส่งผลกระทบต่อสุขภาพอย่างต่อเนื่อง" โดยไม่มีตัวเลขสถานการณ์และไม่มีแหล่งอ้างอิง
ซึ่งเป็นจุดที่กรรมการมักถาม ควรเพิ่มตัวเลขจำนวนวันที่ค่าฝุ่นเกินมาตรฐาน
หรือจำนวนผู้ป่วยที่เกี่ยวข้อง พร้อมระบุที่มา

**ย่อหน้าที่สองของ 1.1 ขึ้นต้นว่า "จึงพัฒนา"** ไม่มีประธานของประโยค และซ้ำคำว่า "จึง"
กับย่อหน้าแรกที่จบด้วย "โครงงานนี้จึงมุ่งพัฒนาระบบ…" อ่านแล้วเหมือนเขียนซ้ำสองรอบ
แก้โดยรวมสองย่อหน้าเข้าด้วยกัน หรือเปลี่ยนย่อหน้าที่สองเป็น
"ผู้จัดทำจึงพัฒนาระบบแสดงค่าฝุ่น PM2.5 และคำแนะนำสุขภาพ…"

**การจัดหน้า** หน้า 4 มีบรรทัดว่างต่อท้ายตารางประมาณสิบบรรทัด และหน้า 16 เกือบ
ว่างทั้งหน้าก่อนขึ้นบทที่ 3 ถ้าสาขากำหนดรูปแบบการขึ้นบทใหม่ไว้ ให้ใช้การแบ่งหน้า
แทนการเคาะบรรทัดว่าง
