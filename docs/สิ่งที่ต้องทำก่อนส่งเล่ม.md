# สิ่งที่ต้องทำเองก่อนส่งเล่ม

รวมรายการจากทุกบทไว้ที่เดียว เป็นงานที่ผู้จัดทำต้องทำเอง
เพราะเป็นข้อมูลที่ไม่ได้อยู่ในระบบ หรือเป็นตัวเลขที่เปลี่ยนตามเวลา

## บทที่ 1 บทนำ

1. เพิ่มหัวข้อ 1.8 แผนการดำเนินงาน ใส่ช่วงเวลาตามปฏิทินของสาขา
   ผู้จัดทำต้องกรอกเอง เพราะเป็นกำหนดการของหลักสูตร ไม่ใช่ข้อมูลที่อยู่ในระบบ
2. เปิดหน้าต้นทางของกรมควบคุมโรคโดยตรง แทนการอ้างผ่านสำนักข่าว แล้วเติมวันที่เข้าถึง
3. ตรวจจำนวนค่าฝุ่นที่สะสมอีกครั้ง ณ วันที่พิมพ์เล่มจริง เพราะระบบเก็บเพิ่มทุกชั่วโมง
4. เติมวันที่เข้าถึงของทุกเว็บไซต์ในรายการอ้างอิง ตามรูปแบบที่สาขากำหนด
5. ตรวจเลขรุ่นในตารางหัวข้อ 1.6 อีกครั้ง ณ วันที่พิมพ์เล่มจริง เพราะแพ็กเกจฝั่งหน้าเว็บ
   อัปเดตรุ่นย่อยได้เอง ตรวจจากรุ่นที่ติดตั้งจริง ไม่ใช่จากเลขที่ประกาศไว้ในไฟล์รายการแพ็กเกจ
6. ถ้าต้องเพิ่มหัวข้อค่าใช้จ่าย ต้องยืนยันสามข้อนี้ด้วยตนเองก่อน เพราะไม่ใช่ข้อมูล
   ที่อยู่ในระบบ ได้แก่ เงื่อนไขการใช้งานและค่าบริการของ Open-Meteo ค่าธรรมเนียม
   ของข้อมูลผู้ป่วยที่ขอจากกรมควบคุมโรค และโควตางานอัตโนมัติของบัญชี GitHub ที่ใช้
7. ข้อความที่ระบุว่างานพยากรณ์ฝุ่นในประเทศไทยใช้แบบจำลอง WRF-Chem ในหัวข้อ 1.5.2
   เป็นภาพรวมจากงานวิจัยและข่าว ยังไม่ใช่เอกสารทางการของกรมควบคุมมลพิษ
   ต้องหาต้นทางยืนยันอีกชั้นก่อนนำไปเขียนในเล่ม

## บทที่ 2 ทฤษฎีและงานวิจัยที่เกี่ยวข้อง

1. เติมวันที่เข้าถึงของทุกเว็บไซต์ในรายการอ้างอิง ตามรูปแบบที่สาขากำหนด
2. ข้อความที่ระบุว่างานพยากรณ์ฝุ่นในประเทศไทยใช้แบบจำลอง WRF-Chem (หัวข้อ 2.4)
   เป็นภาพรวมจากงานวิจัยและข่าว ยังไม่ใช่เอกสารทางการของกรมควบคุมมลพิษ
   ต้องหาต้นทางยืนยันอีกชั้นก่อนส่งเล่ม
3. ตารางเกณฑ์ AQI ในหัวข้อ 2.2.1 ควรอ้างอิงประกาศของกรมควบคุมมลพิษโดยตรง
   แทนการอ้างจากโค้ดของระบบ ให้เปิดหน้าประกาศแล้วเติมรายการอ้างอิง
4. ตรวจสอบเอกสาร `docs/related-work.md` ด้วยตนเองก่อนนำมาใช้ เพราะตารางนั้น
   เขียนจากความเข้าใจภาพรวม ยังไม่ได้ตรวจสอบระบบของ IQAir และ Sensor for All จริง

## บทที่ 3 ขั้นตอนการดำเนินงานและการทดสอบ

1. ดึงตัวเลขในตารางที่ 3.3 ที่ 3.5 และที่ 3.6 ใหม่ ณ วันที่พิมพ์เล่ม เพราะระบบเก็บข้อมูล
   และออกค่าพยากรณ์เพิ่มทุกวัน จำนวนคู่และจำนวนจังหวัดที่เทียบได้จะมากขึ้น
   และค่าความแม่นจะเปลี่ยน
2. เพิ่มแผนภาพสถาปัตยกรรมระบบในหัวข้อ 3.2.1 และแผนภาพความสัมพันธ์ของตาราง
   ในหัวข้อ 3.2.2 เนื่องจากสาขาส่วนใหญ่กำหนดให้บทนี้ต้องมีแผนภาพ
3. เพิ่มหัวข้อ 3.6 แผนการดำเนินงาน พร้อมตารางเวลาตามปฏิทินของสาขา
4. หากสาขากำหนดให้มีการประเมินความพึงพอใจของผู้ใช้ ต้องออกแบบแบบสอบถาม
   และเก็บข้อมูลเพิ่ม ซึ่งยังไม่ได้ทำในขอบเขตปัจจุบัน
