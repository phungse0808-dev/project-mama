# บทคัดย่อ (ร่าง)

**คำสำคัญ** : ฝุ่น PM2.5, คุณภาพอากาศ, คำแนะนำสุขภาพ, ข้อมูลเปิด, Python, FastAPI, React, SQLite

## บทคัดย่อ

โครงงานนี้เป็นการออกแบบและพัฒนาระบบเว็บแสดงค่าฝุ่น PM2.5 และคำแนะนำสุขภาพ
โดยมีจุดประสงค์เพื่อให้ประชาชนทราบว่าพื้นที่ของตนมีค่าฝุ่นเท่าใด อยู่ในระดับใดตามมาตรฐาน
ของประเทศไทย และควรปฏิบัติตัวอย่างไรเมื่อมีโรคประจำตัว โดยรวบรวมข้อมูลจากแหล่งเปิด
ที่ตรวจสอบย้อนกลับได้มาไว้ในระบบเดียว

ระบบพัฒนาด้วย Visual Studio Code ส่วนเซิร์ฟเวอร์ใช้ภาษา Python เวอร์ชัน 3.14 ร่วมกับ
FastAPI เวอร์ชัน 0.141.1 ในการให้บริการ API และใช้ฐานข้อมูล SQLite เวอร์ชัน 3.50.4
ส่วนหน้าเว็บใช้ React เวอร์ชัน 19.2 และ TypeScript ร่วมกับ Leaflet และ Recharts
ข้อมูลที่ใช้เป็นข้อมูลเปิดทั้งหมด ได้แก่ ค่าฝุ่นรายชั่วโมงจาก Air4Thai ของกรมควบคุมมลพิษ
174 สถานี ใน 74 จังหวัด ข้อมูลอุตุนิยมวิทยาจาก NASA POWER พยากรณ์อากาศจาก Open-Meteo
และจำนวนผู้ป่วย 4 กลุ่มโรคที่เกี่ยวข้องกับฝุ่น 110,540 ราย ใน 5 จังหวัด ซึ่งจัดเก็บไว้
ในฐานข้อมูลของระบบสำหรับการวิเคราะห์ เนื่องจากต้นทาง
เปิดเผยเฉพาะค่า ณ ชั่วโมงล่าสุด ระบบจึงเก็บข้อมูลอัตโนมัติทุกชั่วโมงผ่าน GitHub Actions
ปัจจุบันสะสมได้กว่า 70,000 รายการ ผู้ใช้ดูค่าฝุ่นรายจังหวัดและรายสถานี แผนที่คุณภาพอากาศ
อันดับจังหวัด การแจ้งเตือนพื้นที่เสี่ยง กราฟสภาพอากาศย้อนหลัง และคำแนะนำการปฏิบัติตัว
ตามระดับฝุ่นและโรคประจำตัวที่เลือกไว้

ระบบใช้งานได้ตามที่ออกแบบไว้ โดยข้อมูลทุกส่วนเป็นข้อมูลจริงที่ระบบดึงมาเอง อย่างไรก็ตาม
ส่วนพยากรณ์ยังเป็นการสาธิต เพราะผลย้อนทดสอบ 163 จังหวัด-วัน มีความคลาดเคลื่อนเฉลี่ย
3.07 ไมโครกรัมต่อลูกบาศก์เมตร ซึ่งมากกว่าการใช้ค่าของวันก่อนหน้าที่คลาดเคลื่อน 1.93
และข้อมูลผู้ป่วยมีเพียง 5 จังหวัดในปีเดียว จึงยังสรุปความสัมพันธ์เชิงสถิติไม่ได้ ในอนาคต
ควรเก็บข้อมูลให้ครบทุกฤดูกาล ปรับค่าน้ำหนักในสูตรพยากรณ์จากข้อมูลย้อนหลัง และพัฒนา
ให้ใช้งานบนโทรศัพท์มือถือได้สะดวกยิ่งขึ้น
