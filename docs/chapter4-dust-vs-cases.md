## 2. วิธีวิเคราะห์ สามมุม

ใช้ค่าสหสัมพันธ์แบบเพียร์สันระหว่างค่าฝุ่นเฉลี่ยรายเดือนกับจำนวนผู้ป่วยรายเดือน
ของจังหวัดเดียวกัน โดยคำนวณสามแบบ เพราะแต่ละแบบควบคุมตัวแปรต่างกัน

1. **รวมทุกจังหวัด** ใส่ทุกคู่ลงไปคำนวณทีเดียว
2. **ในจังหวัดเดียวกัน** แปลงทั้งค่าฝุ่นและจำนวนผู้ป่วยเป็นส่วนต่างจากค่าเฉลี่ยของจังหวัดนั้น
   ตัดผลของขนาดจังหวัดออก
3. **ตัดฤดูกาลออก** ใช้ค่าเฉลี่ยของเดือนปฏิทินเดียวกันในจังหวัดนั้นเป็นค่าปกติ
   เหลือคำถามว่าปีที่เดือนนั้นฝุ่นหนักกว่าปกติ มีผู้ป่วยมากกว่าปกติหรือไม่

## 4. เจาะเฉพาะภาคเหนือช่วงเผา

ค่าเฉลี่ยทั้งประเทศกลบพื้นที่ที่มีปัญหาฝุ่นรุนแรงที่สุดจนหมด จึงแยกวิเคราะห์เฉพาะ
10 จังหวัดภาคเหนือ คือ เชียงใหม่ เชียงราย แม่ฮ่องสอน ลำปาง ลำพูน น่าน แพร่ พะเยา
ตาก และอุตรดิตถ์ และแยกเฉพาะเดือนกุมภาพันธ์ถึงเมษายนซึ่งเป็นฤดูเผา

**ข้อสังเกต** เมื่อดูเฉพาะช่วงเผา กลุ่มโรคที่ไม่ใช่โรคติดเชื้อได้ค่าบวกเกือบทั้งหมด
ซึ่งเป็นกลุ่มที่ฝุ่นน่าจะมีผลโดยตรง ส่วนกลุ่มโรคติดเชื้อยังติดลบตามฤดูของตัวเอง
รูปแบบนี้สอดคล้องกับที่ทฤษฎีคาดไว้ แต่ข้อมูลช่วงเผามีเพียง 90 คู่ ค่าจึงแกว่งง่าย
ต้องถือเป็นข้อสังเกต ไม่ใช่ข้อสรุป

### 4.1 ข้อจำกัดสำคัญของค่าฝุ่นที่ใช้

ค่าฝุ่นเฉลี่ยของภาคเหนือที่คำนวณได้อยู่ที่ 15.8 ซึ่ง**ต่ำกว่า**ค่าเฉลี่ยทั้งประเทศที่ 16.4
และค่าสูงสุดรายเดือนของภาคเหนืออยู่ที่ 49.9 ขณะที่ทั้งประเทศสูงสุด 82.7

ตัวเลขนี้ขัดกับสถานการณ์จริงที่ทราบกันทั่วไปว่าภาคเหนือช่วงเผามีค่าฝุ่นสูงที่สุดของประเทศ
สาเหตุคือแบบจำลองระดับโลกที่ใช้ดึงค่าย้อนหลังประเมินฝุ่นจากการเผาในที่โล่งต่ำกว่าความจริง
ผลการวิเคราะห์ภาคเหนือในบทนี้จึงอ่อนกว่าที่ควรเป็น ไม่ใช่เพราะฝุ่นไม่มีผล
แต่เพราะค่าฝุ่นที่ใช้ไม่สะท้อนของจริง

แนวทางแก้คือขอข้อมูลค่าฝุ่นย้อนหลังจากสถานีตรวจวัดของกรมควบคุมมลพิษโดยตรง
เมื่อได้แล้วสามารถวิเคราะห์ซ้ำด้วยวิธีเดิมได้ทันที โดยเปลี่ยนเฉพาะแหล่งข้อมูลค่าฝุ่น

## 5. ตัวแปรแฝงที่พบ ฤดูของโรคติดเชื้อสวนทางกับฤดูฝุ่น

ค่าติดลบในมุมที่สองไม่ได้แปลว่าฝุ่นทำให้ป่วยน้อยลง แต่เกิดจากฤดูกาล

| เดือน | ค่าฝุ่นเฉลี่ย | ผู้ป่วยทางเดินหายใจเฉลี่ยต่อปี |
| --- | ---: | ---: |
| ม.ค. | 20.3 | 1,227,391 |
| ก.พ. | 23.8 | 1,032,397 |
| มี.ค. | **28.6 สูงสุด** | 874,811 |
| เม.ย. | 26.9 | **618,577 ต่ำสุด** |
| ก.ค. | 9.8 | สูง |
| ก.ย. | **11.0 ต่ำสุด** | **สูงสุดของปี** |

เดือนเมษายนค่าฝุ่นยังสูงแต่ผู้ป่วยต่ำที่สุดของปี เพราะเป็นช่วงปิดภาคเรียนและเทศกาลสงกรานต์
ซึ่งทั้งลดการแพร่เชื้อในโรงเรียนและลดการเข้ารับบริการ ส่วนเดือนกันยายนค่าฝุ่นต่ำที่สุด
แต่ผู้ป่วยสูงที่สุด เพราะเป็นฤดูฝนซึ่งเป็นฤดูของโรคติดเชื้อทางเดินหายใจ

เนื่องจากกลุ่มโรคติดเชื้อทางเดินหายใจส่วนบนคิดเป็นร้อยละ 73.1 ของผู้ป่วยทั้งหมด
รูปแบบฤดูของกลุ่มนี้จึงลากค่ารวมให้ติดลบ เมื่อตัดฤดูกาลออกในมุมที่สาม
ค่าติดลบก้อนใหญ่หายไปเหลือ −0.06 ซึ่งยืนยันว่าเป็นผลของฤดูกาลจริง

## 6. สรุป

1. **ไม่พบความสัมพันธ์ระหว่างค่าฝุ่นรายเดือนกับจำนวนผู้ป่วย** หลังควบคุมทั้งขนาดจังหวัด
   และฤดูกาล ทุกกลุ่มโรคอยู่ระหว่าง −0.11 ถึง −0.03
2. **การไม่ควบคุมตัวแปรทำให้สรุปผิดได้สองทาง** ไม่ควบคุมขนาดจังหวัดจะได้ค่าประมาณศูนย์
   ซึ่งดูเหมือนไม่มีอะไร ไม่ควบคุมฤดูกาลจะได้ค่าติดลบ ซึ่งชวนให้สรุปกลับด้าน
   ข้อค้นพบนี้เป็นผลหลักของบท
3. **การไม่พบไม่ได้แปลว่าฝุ่นไม่มีผลต่อสุขภาพ** แต่แปลว่าข้อมูลรายเดือนระดับจังหวัด
   หยาบเกินกว่าจะเห็นผลที่มีขนาดเล็ก งานวิจัยที่พบผลมักใช้ข้อมูลรายวันและควบคุม
   ตัวแปรร่วมมากกว่านี้

## 8. สิ่งที่ควรทำต่อ

1. ขอข้อมูลรายวันแทนรายเดือน เพื่อให้เห็นผลระยะสั้นที่ข้อมูลรายเดือนกลบไป
2. ใช้ค่าฝุ่นที่สถานีตรวจวัดจริงเมื่อระบบเก็บสะสมครบปี แทนค่าจากแบบจำลอง
3. ควบคุมตัวแปรร่วมเพิ่ม เช่น อุณหภูมิ ความชื้น และการระบาดของโรคติดเชื้อ
4. แยกวิเคราะห์เฉพาะภาคเหนือช่วงเผา ซึ่งค่าฝุ่นสูงกว่าภาคอื่นมากและอาจเห็นผลชัดกว่า

## 9. ภาคผนวก ขั้นตอนการเตรียมข้อมูล

   ตรงกับจำนวนที่ระบุในเอกสารกำกับข้อมูลของต้นทาง
